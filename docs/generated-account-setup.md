# Base timetable and optional accounts

The supplied college timetable is the base timetable. Teacher account creation and teacher assignment are not prerequisites for classes, room occupancy, cancellation reports, or rescheduling. Existing weekly subjects, periods, classrooms and course staff lists are retained. Cancellation changes apply to the reported date; the recurring base timetable remains unchanged.

Temporary login accounts can optionally be created from Admin → Classrooms. This action creates accounts only and does not assign teachers or alter the timetable. Download the private login list before leaving the page.

The supplied timetable has regular classes Monday–Friday. A Saturday or Sunday dashboard can correctly show no classes today; use the weekly timetable to see all periods.
